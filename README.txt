■ 실시간 분석 대시보드 (전국 매장 200개) — 제출 전 확인

[구성 파일]
1) 실시간_분석_대시보드.html   : 16:9 대시보드 (더블클릭 실행, 인터넷 없이도 내장 샘플로 동작)
2) 소스1_전국지점정보.xlsx     : 소스 ① 전국 가상 지점 200개 (지점ID·지점명·시도·시군구·주소·위도·경도·매장유형·면적·개점일·점장)
3) 소스2_판매주문내역.xlsx     : 소스 ② 판매·주문 내역 3,316행 (주문ID·주문일시·지점ID·지점명·시도·판매 물건(주문 물품)·카테고리·가격·수량·할인율·총 판매금액·판매자·결제수단)
4) photo.jpg                   : 상단 인적사항 증명사진 (HTML과 같은 폴더)
4) csv/                        : 같은 데이터의 CSV 버전 (구글 시트 가져오기용)

[구글 드라이브·시트 연결 방법 — 소스 2개]
 1. 소스1·소스2 xlsx를 구글 드라이브에 업로드 → 더블클릭 → "Google Sheets로 열기"
 2. 각 시트 [공유] → "링크가 있는 모든 사용자 · 뷰어"
 3. 주소창의 /edit 주소 복사 (pub·CSV 게시 주소는 CORS 오류 'Failed to fetch' 발생 → 사용 금지)
 4. 대시보드 헤더 하단 링크 ①(지점) / 링크 ②(판매)에 붙여넣고 [불러오기]
    → 상태 칩이 "연결됨"으로 바뀌고 헤더 태그가 GOOGLE SHEETS LIVE로 바뀝니다
 5. 현재 소스 ①·② 링크는 대시보드 기본값으로 설정되어 있습니다. 처음 열면 자동으로 두 시트를 불러옵니다. 다른 링크로 바꾸려면 각 입력창에서 새 주소를 입력하고 [불러오기]를 누르세요.
 ※ 시트의 첫 행(헤더) 이름은 바꾸지 마세요. 값을 수정하면 60초 자동 갱신 또는 [불러오기]로 즉시 반영됩니다.

[지도 (Leaflet + OpenStreetMap)]
 - Google Maps 키 없이 Leaflet으로 전국 지점 지도를 표시합니다.
 - 지도 타일은 인터넷 연결이 필요합니다. 하단의 OpenStreetMap 출처 표기를 유지하고, 일반적인 대화형 열람 외에 타일을 대량 수집하거나 오프라인 저장하지 마세요.
 - Leaflet CDN 또는 지도 타일을 불러오지 못하면 내장 스타일 지도로 대체됩니다.

[Gemini 호출 준비 — 브라우저 직접 호출]
 - 대시보드 HTML의 CONFIG.GEMINI_KEY에 Gemini API 키가 설정되어 있습니다. Gemini 3.8 Flash를 선택하고 [분석 실행]을 누르면 Google Gemini API를 직접 호출합니다.
 - API 키는 HTML 소스와 브라우저 네트워크 요청에서 확인할 수 있습니다. 공개 배포 시 누구나 키를 사용할 수 있으므로 Google AI Studio에서 키별 API 제한과 사용량 한도를 설정하세요.
 - 로컬 분석도 사용할 수 있으며, Gemini 호출에 실패하면 LOCAL 분석으로 자동 대체됩니다.

[인적사항 수정] HTML에서 Ctrl+F "PROFILE" → name / studentId / dept / date 수정, 사진은 photo.jpg 교체.

※ 모든 지점·판매·판매자 데이터는 교육 실습용 가상 데이터입니다.
